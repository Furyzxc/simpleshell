SimpleShell User Manual

cd <directory>
    Changes the current directory.
pwd
    Present working directory.
clr
    Clears the screen.

dir <directory>
    Lists contents of a directory.

environ
    Displays environment variables.

echo <text>
    Prints text to the screen.

pause
    Pauses the shell until Enter is pressed.

quit
    Exits the shell.

External Commands
    The shell executes programs using fork and exec.

I/O Redirection
    Use <, >, >> to redirect input/output.

Background Execution
    Use & to run programs in background.
